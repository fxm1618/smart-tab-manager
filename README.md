# Smart Tab Manager 🚀

**⭐ Free Chrome Extension for Tab Management**

[![GitHub stars](https://img.shields.io/github/stars/fxm1618/smart-tab-manager?style=social)](https://github.com/fxm1618/smart-tab-manager)
[![License](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)

> 🎯 Organize 100+ tabs instantly with AI-powered categorization

## ✨ Features

- 🔍 **Instant Search** - Find any tab in milliseconds
- 📁 **AI Auto-Group** - Smart categorization (Work, Social, Shopping, etc.)
- 💾 **Session Save** - Save and restore tab sets
- ⚡ **Memory Saver** - Auto-suspend inactive tabs
- 🎨 **Color Groups** - Visual organization

## 🚀 Quick Start

### Install Locally (Free)

```bash
git clone https://github.com/fxm1618/smart-tab-manager.git
cd smart-tab-manager
```

1. Open Chrome → `chrome://extensions/`
2. Enable "Developer mode"
3. Click "Load unpacked"
4. Select the `smart-tab-manager` folder
