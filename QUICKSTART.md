# Quick Start Guide

## Installation (2 minutes)

### Option 1: Load Unpacked (For Testing)
1. Open Chrome
2. Go to `chrome://extensions/`
3. Toggle "Developer mode" ON (top right)
4. Click "Load unpacked"
5. Select the `smart-tab-manager` folder
6. Done! Icon appears in toolbar

## First Use (30 seconds)

1. **Open the extension**
   - Click the 🧠 icon in toolbar
   - Or press `Ctrl+Shift+T` (Mac: `Cmd+Shift+T`)

2. **Try the search**
   - Type in the search box
   - Click any tab to switch to it

3. **Auto-organize**
   - Click "📁 Auto Group" button
   - Watch tabs organize by category

4. **Save your session**
   - Click "💾 Save Session"
   - Restore anytime from saved sessions

## Tips & Tricks

### Keyboard Shortcut
Set up custom shortcut:
1. Go to `chrome://extensions/shortcuts`
2. Find "Smart Tab Manager"
3. Set your preferred key combo

### Categories Explained
- **Work**: Docs, Slack, Zoom, GitHub, Jira
- **Social**: Facebook, Twitter, LinkedIn, Reddit
- **Shopping**: Amazon, eBay, online stores
- **Entertainment**: YouTube, Netflix, Spotify
- **News**: News sites, Medium, blogs
- **Other**: Everything else

### Best Practices
- Use search for quick tab switching
- Group tabs when you have 10+ open
- Save sessions for different projects
- Upgrade to Pro for auto-suspend

## Troubleshooting

**Extension not showing?**
- Check if enabled in chrome://extensions/
- Try reloading the extension

**Search not working?**
- Refresh the popup
- Check tab permissions are granted

**Groups not creating?**
- Ensure you have multiple tabs in same category
- Try manually grouping first
